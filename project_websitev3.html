About Our Project

Our group created a Car Dealership Management System using Python. The program allows users to view, add, modify, and delete cars.

We used Tkinter to create the interface and a CSV file to save car information. We also added a text-to-speech feature that reads instructions out loud.

Our goal was to create a simple and easy-to-use program using the tools we learned from class while learning more about Python.

Created by Tai Tran, John Fernan, Brianna Nguyen, and Daniel Nguyen
